{% comment %} Messages are grouped by sender rather than stamped one by one. A run of four lines from the same person is one person talking, and repeating their face and name against each line is four times the furniture for no extra information. The ifchanged tag is what does the grouping: it fires only on the iteration where the value differs from the previous one. Three of them run here — the date chip, the "head" class, and whether the face and name are printed — and each keeps its own state, so the last two fire together on the same messages. The date chip is the same idea a level up.
